# User Stories

## Owner (Solomon)

As the owner, I want to:

- See all active trucks.
- Know which trucks are delayed.
- Approve material purchases.
- View daily revenue.
- View unpaid customer balances.
- Compare garage branches.
- Know who is working on each truck.

---

## Operations Manager (Daniel)

As the operations manager, I want to:

- Register incoming trucks.
- Create a job card.
- Assign mechanics.
- Track repair progress.
- Record additional repairs.
- Request spare parts.
- Mark repairs as completed.
- Find any truck quickly.

---

## Accountant

As the accountant, I want to:

- View completed jobs.
- Generate invoices.
- Record customer payments.
- Record supplier payments.
- Calculate mechanic payments.
- Generate financial reports.

---

## Procurement Assistant

As the procurement assistant, I want to:

- View approved purchase requests.
- Record purchased materials.
- Record supplier information.

---

## Mechanic (Future)

As a mechanic, I want to:

- View my assigned work.
- Request parts.
- Mark work as completed.
