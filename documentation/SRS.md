# Heavy Truck Garage Management System

## Vision

Build a digital management system for heavy truck garages in Ethiopia.

The system will help owners, managers, and accountants manage truck repairs, mechanics, spare parts, suppliers, finances, and customers.

---

## Main Users

1. Owner
2. Operations Manager
3. Accountant
4. Procurement Assistant
5. Mechanic (future)

---

## Main Goal

Replace paper-based workflow with a digital system that is easier, faster, and more reliable.

---

## MVP Goal

The first version should allow:

- Register incoming trucks
- Create job cards
- Assign mechanics
- Track repair progress
- Track spare parts requests
- View active trucks
